# skills

Collection of reusable skills — starting with `gws-drive` for Google Drive v3 API automation via the `gws` CLI.

## Skills

| Skill | Description |
|-------|-------------|
| [gws-drive](./gws-drive/SKILL.md) | Google Drive: Comprehensive command suite and API resource management via the official gws CLI. |

## Usage

Each skill is a self-contained directory with a `SKILL.md`. Install via OpenCode / Claude Code by copying the skill directory to your skills path.
